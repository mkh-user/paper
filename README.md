# Paper
Just a page to type in browser with all browser tools

---

I have a complete set of writing tool in my browser (spell and grammar checker, translator, AI inline edits), so why I should need another plaintext editor or notepad? Answer is I don't need, so this repo is just a "paper", I use <https://mkh-user.github.io/paper> to write with all of my writing tools I already have in my browser (because some tools aren't available in local `.html` files).

_You can use it yourselves too, but note that it's RTL by default and there is really NO FEATURE (no saving, no tools by itself, no multiple notes at a time (you can open multiple tabs still))_

**Note:** Tools I use are:
- Microsoft Edge's default spell checker
- Microsoft Editor Extension
- [sider.ai](https://sider.ai) Extension
- Simple Translate Extension
