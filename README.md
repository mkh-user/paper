# Paper
Just a page to type in browser with all browser tools

---

I have a complete set of writing tools in my browser (spell and grammar checker, translator, AI inline edits), so why would I need another plaintext editor or notepad? The answer is I don't, so this repo is just a "paper." I use <https://mkh-user.github.io/paper> to write with all of my writing tools I already have in my browser (because some tools aren't available in local `.html` files).

_You can use it yourselves too, but note that it's RTL by default, and there are really NO FEATURES (no saving, no tools by itself, no multiple notes at a time (you can still open multiple tabs))._

**Note:** Tools I use are:
- Microsoft Edge's default spell checker
- Microsoft Editor Extension
- [sider.ai](https://sider.ai) Extension
- Simple Translate Extension
